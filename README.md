# Chibueze Gozie Paul: Model Portfolio

React + Vite.

1. Unzip, open the folder in VS Code
2. Terminal: `npm install`
3. `npm run dev` and open the link it prints
4. `npm run build` makes a `dist/` folder to upload to Netlify, Vercel or any host

Edit text, contact details, stats and photo captions in `src/data.js`.
Put new photos in `public/images/` and add a line for each in `photos`.
